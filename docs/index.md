# Reel Uploader

Reel Uploader is a privately operated content-publishing application used by its owner and authorized administrators. It is not offered as a public software-as-a-service product.

The application connects only to Facebook Pages and Instagram accounts for which access has been authorized. It uses Meta APIs to publish and manage authorized content.

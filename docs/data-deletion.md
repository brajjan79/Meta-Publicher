# Data Deletion Instructions

Reel Uploader is a private content-publishing application used only by its owner and authorized administrators.

## Revoke access

To stop Reel Uploader from accessing a Facebook Page or Instagram account, remove the application's authorization using the applicable Facebook or Instagram settings. Meta controls the location and wording of these settings, which may change. Look for the area that manages apps, websites, business integrations, or connected experiences, select Reel Uploader, and remove or revoke its access.

Revoking access prevents future authorized API requests but may not by itself delete information previously associated with the application.

## Request deletion

To request deletion of data associated with Reel Uploader:

1. Contact the repository owner through the contact options on the [Meta-Publicher GitHub repository](https://github.com/brajjan79/Meta-Publicher) or the owner's linked GitHub profile.
2. State that the request concerns **Reel Uploader data deletion**.
3. Provide only the minimum information needed to identify the connected Facebook Page or Instagram account, such as its name or public account/Page identifier.
4. Do **not** include passwords, access tokens, app secrets, or other credentials.

The owner will use the supplied account details to identify and delete application-associated data under the owner's control, where applicable, and will confirm when the request has been handled. Information controlled by Meta must be managed through Meta's own account tools and policies.
